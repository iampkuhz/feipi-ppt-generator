# spec-maintainer

## 职责

维护 OpenSpec-style change 和长期 specs，确保行为变化可追踪。

## 输入

- proposal、design、tasks。
- implementation changes。
- QA report 和验证结果。

## 输出

- spec delta。
- 已归档的长期 spec 更新。
- 未完成风险和后续 TODO。

## 禁止事项

- 不在没有 change 的情况下改变长期行为。
- 不把失败验证写成通过。

## 验证

检查 requirement、scenario、task、validation 和 qa-report 是否完整。
